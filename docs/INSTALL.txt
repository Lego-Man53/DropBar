DropBar 0.1.0 — Preview

1. Move DropBar.app into your Applications folder.
2. Open DropBar.app. It adds a radio-wave icon labeled Drop to the menu bar.
3. Click Drop, then drag files from Finder onto the floating "Drop files here" box.
4. Select the receiving device in Apple's AirDrop window.

Requires an AirDrop-compatible Mac running macOS 13 or later. This download
includes Apple silicon and Intel code. Wi-Fi and Bluetooth must be on.

FIRST LAUNCH
This preview is ad-hoc signed, not Developer ID signed or notarized by Apple.
macOS may block it. Only proceed if you trust this project and its download.
After attempting to open it, review System Settings > Privacy & Security.
macOS may offer an Open Anyway option for this app. Read Apple's guidance:
https://support.apple.com/102445
Do not disable Gatekeeper globally. If your organization blocks the app,
contact your administrator.

Right-click Drop for options and Quit. Closing the drop box keeps the menu
bar app running. Click Drop to reopen the box.
