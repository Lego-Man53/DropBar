# Changelog

## 0.1.0 — 2026-10-05 (Preview)

First open-source preview.

### Included

- Menu bar item labeled **Drop** with native radio-wave symbol.
- Floating file drop area for avoiding screen-edge/Mission Control interference.
- Multiple-file sharing through Apple's AirDrop chooser.
- File picker and right-click actions for Finder's AirDrop and quitting.
- File URL validation and error messages.
- Universal Apple silicon/Intel packaging, SHA-256 checksum, and MIT license.
- Installation, usage, troubleshooting, development, and contribution guides.

### Validation and limitations

- Native builds and file decoding/service-availability checks passed on the development Mac.
- Floating panel and file picker inspected on screen.
- Actual file delivery, Intel hardware, older macOS versions, and full-screen/multi-display combinations remain unverified.
- Ad-hoc signed; not Developer ID signed or Apple-notarized.
- No automatic updates. Download new versions from GitHub Releases.
- Save browser content and other app attachments to Finder before dropping them.
